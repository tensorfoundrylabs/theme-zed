# Syntax gallery

Open these files in Zed to review TensorFoundry's syntax hierarchy across languages. Each example intentionally includes comments, imports or namespaces, types, functions, parameters, properties, constants, strings, numbers, booleans, operators, and language-specific constructs.

For the richest Go preview, enable semantic tokens:

```json
{
  "languages": {
    "Go": {
      "semantic_tokens": "combined"
    }
  }
}
```

Useful review questions:

- Can control flow be found without dominating the file?
- Are types, callable names, parameters, and member data immediately distinct?
- Do package and module qualifiers read differently from ordinary variables?
- Are strings and numbers recognisable without pulling attention from structure?
- Do comments remain comfortably readable during a long session?
