# Changelog

All notable changes to TensorFoundry for Zed are documented here.

## [1.0.0] - 2026-09-19

### Added

- TensorFoundry Dark and TensorFoundry Dark Night.
- Semantically grouped syntax colours for common Tree-sitter and LSP tokens.
- Distinct editor, navigation, tab, panel, menu, dialog, and terminal surfaces.
- Hot-core indicators for unsaved buffers and ember styling for modified files.
- Go semantic-token guidance for package and namespace highlighting.
- Syntax examples for Go, Rust, Python, CSS, Svelte, and Zig.
- Theme previews and a complete colour-palette reference.
